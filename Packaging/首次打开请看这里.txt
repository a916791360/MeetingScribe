MeetingScribe 0.12.1 —— 安装与首次使用
=====================================

系统要求：Apple Silicon（M 系列芯片），macOS 15 或更新版本。
不支持 Intel Mac 或 Windows。

安装
----
1. 解压 ZIP，把 MeetingScribe.app 拖到「应用程序」。
2. 首次双击若被 macOS 拦下，先关闭提示，再到
   「系统设置 → 隐私与安全性 → 安全性」点击「仍然打开」
   （有些系统版本显示「仍要打开」），按系统提示确认。
3. 回到「应用程序」打开 MeetingScribe。

本版本未做 Apple 公证，需要上述首次打开步骤。

第一次使用
----------
· 导入已有音频：点击「导入音频」选择文件即可本地转写。
· 录制会议：按应用提示授予麦克风、屏幕与系统音频录制权限。
  屏幕采集授权用于获取系统声音；新录音只保存音频，不保存屏幕视频。
  授权后若系统要求退出并重新打开应用，请照做，再开始录音。
· 默认使用本地保守整理，不需要 API Key。逐字稿在本机生成；
  保守整理只保留材料中明确的决策和待办，可能不生成速览或纪要。
· 需要大模型整理时，在「设置」配置本机 Ollama 或兼容云端接口。
  使用云端整理时，逐字稿会发往你配置的服务商；本地转写仍离线进行。

包内自带 whisper-cli、依赖动态库和 ggml-small.bin 模型。
使用安装包无需安装 Xcode、Python、whisper.cpp 或另行下载模型。

会议文件存放在 ~/Library/Application Support/MeetingScribe/，
API Key 保存在你自己的 macOS 钥匙串。安装包不含他人的会议或凭据。
升级时替换应用即可；请保留会议文件目录，重要资料建议先备份。
