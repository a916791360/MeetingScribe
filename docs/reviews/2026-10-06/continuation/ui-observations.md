# 0.11.5 原生合成界面复验

通过CUA打开由当前源码编译的独立MSClosureReview.app，单独bundle identifier、合成SessionStorage、延迟假录音器，无真实设备采集或云端请求。

- 最近会议4条，速览显示负责人“审查甲”。
- 点击开始录音后显示“正在连接采集设备，尚未确认开始录音”；导入禁用，顶部有取消录音准备。
- 取消后显示“已取消录音准备”，开始录音恢复，无系统故障弹窗。
- 原文每句有“修改这一句”AX标签，校正框包含speaker及时间。
- 点击校正输入框、全选并粘贴合成句“审查甲下周二交付报价单。”后，⌘Return保存，显示“已人工校正1处”和新句。
- 切换纪要显示“原文已更新，速览与纪要基于修改前的内容，请重新整理。”，旧纪要继续可见。
- 单独的typeText尝试没有改变文本，随后显式聚焦+paste成功；这是工具交互观察，不是产品键盘故障证据。
- 退出隔离App后仅检查真实App空闲，再正常退出升级；未保存真实会议截图或正文到证据。

这些观察不等同于VoiceOver实际朗读、真实设备权限与采集、长文性能验收。
