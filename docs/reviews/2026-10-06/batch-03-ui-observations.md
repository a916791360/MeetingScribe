```text

```

均未显示“基于旧原文”或“需重新整理”。实际 UI 导出已归档为 batch-03-ui-export.md；同时含旧纪要和新原文。保存面板把 Save As 输入框内的绝对路径当作文件名处理，合成文件一度落在 Documents，随后只将该合成文件移动至本证据目录；未改动用户已有文件。这是审查操作修正，不作为产品缺陷。

## 正常交互对照

- 设置面板可用 Escape 关闭。
- 合成原文可用 Cmd+Return 保存。
- 6 段夹具的正文及铅笔按钮能被 AX 读取。
- 无音频时显示“暂无可播放音频”和“打开文件夹”，传输控件禁用。
- Markdown 导出实际产生 .md；本批未把 plainText 的类型声明直接认定为扩展名错误。
- 初始 2 段夹具触发材料量门禁，属于既有设计；负责人和过期状态的验证后来使用了 6 段、375 字且有明确模型来源的夹具，避免被历史修补替换。
