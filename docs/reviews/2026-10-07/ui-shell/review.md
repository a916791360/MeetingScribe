# 0.12.0 内容面与导航层级调整

按用户指定的结构实施：浅灰窗口底层承载会议列表，右侧统一内容面承载会议标题、操作、正文和播放器。浅色内容面为纯白，深色使用比窗口底层更亮的表面。

## 实现

- `WorkbenchView.swift`：以并排工作区替换 `NavigationSplitView`，避免系统浮动侧栏遮盖内容。左栏宽 280 pt；右侧内容面圆角 16 pt，外侧留白 12 pt。
- 标题和全局操作从原生工具栏移到内容面页头。空态、加载、录音准备、失败和结果页共用这一层，不重复嵌套工作区容器。
- 侧栏开关始终可见，支持 ⌃⌘S，并保存展开偏好；⌘, 仍能在空态打开设置。
- 辅助功能树按「会议列表 → 会议内容」分组；标题具有 heading 语义，图标按钮有名称。长标题截断显示，悬停与辅助功能保留全文。
- `AppTheme.swift`：新增 `windowCanvas`、`contentSurface`、`contentEdge`，保持原文和结构化内容的 800 pt 最大阅读列宽。
- `WindowConfiguration.swift`：原生标题栏继续承载窗口控制和拖动，会议标题显示在内容面。最低内容尺寸仍为 1060 × 660 pt。
- 本地应用版本 0.12.0 / build 30。录音、转写、持久化和云端逻辑未在本轮修改。

## 实际验收

UI 验收使用独立 bundle ID、合成会议与模拟录音器；没有录制真实会议或发送云端请求。测试源为 [ReviewUIShellHarness.swift](ReviewUIShellHarness.swift)，包含生产 `ContentView` 和窗口配置。

| 场景 | 结果与证据 |
|---|---|
| 浅色，侧栏展开 | 灰底列表与白色内容面分层清楚；见 `light-expanded.png`、`light-expanded-final.png` |
| 侧栏收起、恢复 | 内容面扩展；按钮及 ⌃⌘S 可用；重启仍记住收起状态；见 `light-collapsed-final.png` |
| 最小窗口 | 1060 pt 宽，660 pt 内容高度；标题、操作和播放器无重叠；见 `light-minimum-final.png` |
| 深色 | 侧栏底层、正文面、控件和文字同时适配；见 `dark-expanded.png`、`dark-minimum.png` |
| 空状态 | 两个任务入口可见，⌘, 打开设置；见 `empty-light.png` |
| 录音准备与取消 | 准备状态及取消入口可见，导入禁用；取消后回到可重新开始状态；见 `recording-preparation.png`。此项使用模拟录音器，不代表新增真实录音验收 |
| 长标题 | 在最小窗口以省略号收尾，三个全局操作仍可见；见 `long-title-minimum.png` |
| 长原文与音频 | 1,501 句合成资料可以从第 1–500 句切到第 501–1,000 句；播放按钮变为暂停，进度推进；正文滚动与底部播放器分离 |
| 导入与设置 | 卡片内导入打开原生音频选择器，取消正常返回；设置外观可在浅色与深色之间切换 |
| 辅助功能顺序 | 最终原生 AX 树先列会议列表，再列会议内容，包含标题、按钮和播放器；本轮没有重新验证 VoiceOver 真实朗读 |

首次布局修改运行完整 Swift 回归：371 项，1 项真实云端测试跳过，零失败，详见 `swift-regression.log`。最终补充加载提示与辅助功能分组后，16 项布局、外观、内容规划回归通过，详见 `layout-regression.log`。最终 Release 构建及签名、固定运行时、许可、开发路径审计通过，详见 `package.log`、`staged-audit.log`。
